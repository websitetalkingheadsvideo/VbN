# Character Agent Output Schema

## 1. Markdown Brief (`reports/{cadence}/{character_slug}.md`)
- **Front Matter:** none (plain Markdown for ease of admin preview).
- **Header Block:**
  - `Character: <name>` (fallback `(no name provided)`).
  - `Clan`, `Faction`, `Location`, `Player`.
  - Values escaped for Markdown.
- **Sections:**
  1. `## Summary` — 2-3 paragraphs (max 300 words).
  2. `## Key Traits` — exactly three bullet items (`-` list), draw from abilities/merits.
  3. `## Plot Hooks` — numbered list (1-3) seeded from agent output or deterministic templates.
- **Footer:** `---` separator followed by `*Generated by Character Agent — Valley by Night*`.
- **Cadence:** `daily/` for updated characters since last run; `weekly/` aggregates full roster touches.

## 2. Missing Field JSON (`reports/{cadence}/{timestamp}_{character_slug}_missing.json`)
```json
{
  "character_id": 0,
  "character_name": "",
  "detected_at": "2025-11-12T00:00:00Z",
  "fields": [
    {
      "field": "biography",
      "status": "missing",
      "recommendation": "Add 2-3 paragraph chronicle summary.",
      "current_value": ""
    }
  ]
}
```
- `fields[*].status` ∈ `{"missing","placeholder","stale"}`.
- `detected_at` uses UTC ISO8601.
- File name: `<timestamp>_<character_slug>_missing.json`.

## 3. Continuity Warning JSON (`reports/continuity/{timestamp}_{character_slug}.json`)
```json
{
  "character_id": 0,
  "character_name": "",
  "generated_at": "2025-11-12T00:00:00Z",
  "issues": [
    {
      "type": "relationship_inconsistent",
      "severity": "warning",
      "details": "Reported sire differs from sire field.",
      "related_ids": [12, 98]
    }
  ]
}
```
- `severity` ∈ `{"info","warning","critical"}`.
- `type` enumerated: `relationship_inconsistent`, `timeline_gap`, `duplicate_name`, `missing_sire`.
- `related_ids` optional array of integer ids tied to conflict.

## 4. History Compilation (`reports/history/{timestamp}_city_history.md`)
- Markdown grouped by coterie:
  ```
  # City History — Valley by Night

  ## Coterie: The Shrouded
  ### Sebastian Armitage
  Biography…
  Agent Notes…
  ```
- Append chronological headings using `created_at` / `updated_at`.

## 5. Logging (`logs/agent_activity.log`)
- Append-only JSON line format:
  ```json
  {"timestamp":"2025-11-12T03:45:01Z","character_id":42,"events":["brief_written","missing_fields:appearance"],"duration_ms":145}
  ```
- Write once per processed character plus one summary line per run: `{"timestamp":"...","run_id":"...","processed":12,"skipped":3,"mode":"daily"}`

## 6. Configuration Snapshot (`config/pipeline.php`)
- Strict array return:
  ```php
  <?php
  declare(strict_types=1);

  return [
      'cadence' => 'daily',
      'report_dir' => __DIR__ . '/../reports',
      'continuity_enabled' => true,
      'plot_hooks' => [
          'enabled' => true,
          'max_per_character' => 3,
      ],
      'batch' => [
          'size' => 25,
          'sleep_ms' => 50,
      ],
  ];
  ```
- File consumed via `require` to avoid runtime config mutation.
