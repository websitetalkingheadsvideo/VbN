# Valley by Night — Character Agent

## Purpose
The **Character Agent** monitors, analyzes, and summarizes character data within *Valley by Night*. 
It ensures lore consistency, generates story hooks, and provides concise briefs for storytellers.

## Core Responsibilities
1. Lore Consistency — cross-reference character data and detect contradictions.
2. Creative Support — generate character briefs and plot hooks.
3. Monitoring — watch for updates and log them.
4. Integration — designed to work with future agents and admin tools.

## Folder Structure
See repository layout for data, prompts, reports, and config folders.

## Rules
- No automatic overwrites of canonical files.
- Respect Masquerade tone and Valley by Night lore.
- All NPCs default to `"player_name": "NPC"`.
